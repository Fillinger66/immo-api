About This Project

This page presents an example web project that implements an XGBoost model for real estate price prediction in Belgium.

This project is intended as an example to illustrate the application of machine learning models in the field of real estate estimation.

The Model

To estimate real estate prices, this project utilizes an XGBoost (Extreme Gradient Boosting) model, a powerful and efficient machine learning library well-suited for regression tasks. This model learned complex relationships within a dataset of around 16.000 historical property listings across Belgium, with prices ranging from 50.000€ to 1.000.000€, to provide price predictions. Its performance was then evaluated on a separate test set of around 4000 listings to ensure its accuracy on unseen data.

The performance of our XGBoost model has been evaluated using key metrics, as detailed in the table below. Understanding these metrics helps gauge the reliability of the price estimates.

Metric Full term Value Impact on Price Prediction Link
MAE Mean Absolute Error 46000 € Average error in our predicted property prices for Belgium (46000€ difference from the real price, on average). Wikipedia
RMSE Root Mean Squared Error 70000 € Like MAE, but bigger errors in our price predictions count more, indicating potential for larger inaccuracies in some cases. Wikipedia

The Application

This demonstration website serves as an interface to interact with our XGBoost prediction model. It allows (in the context of this example) to submit characteristics related to a property in Belgium and get an estimated price based on the trained model.
