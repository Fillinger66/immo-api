About This Project

This page presents an example web project that implements an XGBoost model for real estate price prediction in Belgium.

The Model

The core of this project relies on the use of an XGBoost (Extreme Gradient Boosting) model to estimate real estate prices. XGBoost is a powerful and efficient machine learning library, widely used for regression and classification tasks.

The Application

This demonstration website serves as an interface to interact with the prediction model. It allows (in the context of this example) to submit characteristics related to a property in Belgium and obtain a price estimation based on the trained model.
